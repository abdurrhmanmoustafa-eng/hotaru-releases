# Hotaru 蛍

A small firefly voice companion for Windows. It lives at the top of your screen: talk to it, circle things to ask about them, type with your voice, set routines and connect your apps. It thinks with Google's Gemini through your own free API key.

## Install

1. Download `Hotaru_x.y.z_x64-setup.exe` from the [latest release](../../releases/latest).
2. Run it. Windows may say "Windows protected your PC" because the installer isn't code-signed yet: click **More info → Run anyway**.
3. Hotaru opens its setup page: make a free Gemini key in Google AI Studio and paste it in.
4. Hold **Win + Alt** anywhere and talk.

Hotaru updates itself: it checks here for new versions and offers to install them.

This repository only holds the installers; it has no source code.
